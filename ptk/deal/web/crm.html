How automatic sending works (webhook setup)
When a webhook URL is set, the tool sends a POST request with JSON {to, from, subject, body, name, customerId, step} each time an email is due. In Zapier, create a “Catch Hook” trigger and connect it to a “Send Email” (or Gmail/Outlook) action, mapping those fields. Paste the hook URL above. Because browsers can’t send mail directly, this is the only way to make sending fully hands-off.
